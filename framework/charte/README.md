# Charte et tons (transverse)

La forme de tous les livrables (slides, tons de rédaction). Utilisée par tous les départements, jamais « à » un seul.

- Classeurs (`skills/`) : `slide-style`, `voice-slides`, `voice-deliverable`, `voice-maximilien`, `voice-casual`, `voice-adservio`
- Machine : `tones` (code partagé, dans `framework/lib/set_tone.py`)
