# Communication

Rôle : **Chargé de communication**. Mission : comptes rendus, weekly, ordres du jour, relances, transcriptions.

Contenu rangé ici, tel que déclaré dans `framework/organisation.yml` (référentiel unique, contrôlé par
le vérificateur). Ce que fait chaque composant : `framework/SKILLS.md`.

- Collègues (`agents/`, sous-agents) : aucun, Claude principal fait ce travail lui-même
- Classeurs (`skills/`) : aucun, Claude principal fait ce travail lui-même
- Machines (`generators/`, `pm run <nom>`) : `partner-report`, `weekly-report`, `meeting-agenda`, `activity`, `transcripts`, `slack`, `omi-sync`
- Chefs de garde (`routines/`, tâches planifiées) : `draft-followups`, `morning-digest`, `collect-activity`, `omi-sync`
