# Planification

Rôle : **PMO planning**. Mission : planning, plan de sprints, projection de fin, objectifs de sprint.

Contenu rangé ici, tel que déclaré dans `framework/organisation.yml` (référentiel unique, contrôlé par
le vérificateur). Ce que fait chaque composant : `framework/SKILLS.md`.

- Collègues (`agents/`, sous-agents) : `jira-sprints-audit`
- Classeurs (`skills/`) : `technical-planning`
- Machines (`generators/`, `pm run <nom>`) : `planning`, `plan`, `projection`, `jira-sprints-audit`, `notion-planning`
- Chefs de garde (`routines/`, tâches planifiées) : `publish-projection`, `align-sprint-goals`, `track-progress`, `audit-scope`
