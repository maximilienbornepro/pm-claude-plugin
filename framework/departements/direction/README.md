# Direction de projet

Rôle : **Chef de projet**. Mission : cadrer la demande, préparer la mission, vérifier les connexions, décider des gates.

Contenu rangé ici, tel que déclaré dans `framework/organisation.yml` (référentiel unique, contrôlé par
le vérificateur). Ce que fait chaque composant : `framework/SKILLS.md`.

- Collègues (`agents/`, sous-agents) : aucun, Claude principal fait ce travail lui-même
- Classeurs (`skills/`) : `setup`, `list`, `run`, `demo`
- Machines (`generators/`, `pm run <nom>`) : `setup`, `init`, `preflight`, `cockpit`, `method`, `gate`, `templates`, `agent`, `drive-scaffold`, `notion-scaffold`, `console`, `reset`
- Chefs de garde (`routines/`, tâches planifiées) : aucun, Claude principal fait ce travail lui-même
