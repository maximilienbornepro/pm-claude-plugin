# Suivi et gouvernance

Rôle : **Responsable du suivi**. Mission : sujets, risques, RACI, traçabilité, cohérence des documents.

Contenu rangé ici, tel que déclaré dans `framework/organisation.yml` (référentiel unique, contrôlé par
le vérificateur). Ce que fait chaque composant : `framework/SKILLS.md`.

- Collègues (`agents/`, sous-agents) : `notion-topics-audit`
- Classeurs (`skills/`) : aucun, Claude principal fait ce travail lui-même
- Machines (`generators/`, `pm run <nom>`) : `risks`, `raci`, `traceability`, `trace-audit`, `docs-coherence-audit`, `notion-topics-audit`
- Chefs de garde (`routines/`, tâches planifiées) : `review-topics`, `review-risks`
