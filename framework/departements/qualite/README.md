# Qualité du backlog

Rôle : **Responsable qualité**. Mission : tickets propres et à jour, écarts maquette / tickets / contrat d'API.

Contenu rangé ici, tel que déclaré dans `framework/organisation.yml` (référentiel unique, contrôlé par
le vérificateur). Ce que fait chaque composant : `framework/SKILLS.md`.

- Collègues (`agents/`, sous-agents) : `jira-changes-audit`, `jira-tickets-audit`, `front-audit`
- Classeurs (`skills/`) : aucun, Claude principal fait ce travail lui-même
- Machines (`generators/`, `pm run <nom>`) : `jira-changes-audit`, `jira-images`
- Chefs de garde (`routines/`, tâches planifiées) : aucun, Claude principal fait ce travail lui-même
